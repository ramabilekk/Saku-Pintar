📱 Cara Install APK SakuPintar

  1. Tekan tombol Unduh APK untuk mengunduh file .apk terbaru dari GitHub Releases.
  2. Buka file APK di HP Android Anda (izinkan instalasi dari browser jika diminta).
  3. Masuk menggunakan akun Google yang sama agar seluruh catatan pengeluaran, tabungan, dompet, dan anggaran langsung tersinkronisasi otomatis antara Web & APK!
