Hubungkan Firebase Web (Sinkron APK)

Untuk sinkronisasi Google Sign-In & Firestore dua arah dengan APK Android di proyek gen-lang-client-0625297800, masukkan Web API Key & Web App ID dari Firebase Console → Project Settings → Your apps (Web), dan pastikan domain localhost sudah ditambahkan di Authentication → Settings → Authorized domains.

Panduan Pasang SakuPintar APK

  1. Tekan tombol Download APK Sekarang untuk mengunduh file rilis resmi terbaru dari GitHub Releases.
  2. Buka file .apk yang selesai diunduh melalui notifikasi atau aplikasi Files di Android.
  3. Jika Android meminta izin pemasangan, aktifkan Izinkan dari sumber ini (Install unknown apps) lalu lanjutkan instalasi.
  4. Buka SakuPintar di HP Anda dan pilih Masuk dengan Google memakai akun Google yang sama dengan browser ini — semua transaksi, anggaran, dompet, dan celengan langsung tersinkron!
